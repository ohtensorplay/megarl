# MegaRL — Brand Identity v0.1

Concept proposal, not official. The independent MegaRL repository and supported features were not verified in public sources. Reinforcement learning infrastructure is the provisional product category; no claims about supported algorithms, hardware, distributed execution or performance are implied.

## Research
- TensorPlay: https://tensorplay.org/ — transparent deep learning framework.
- MEGA Hub: https://mega.tensorplay.cn/ — models, datasets and AI services.
- Organization: https://github.com/ohtensorplay — public repository list, no independent MegaRL repository located in this research pass.
- MegaLM v0.1: sibling concept supplied in the previous design round.

## Identity
- Name: **MegaRL** (proposed capitalization; consistent with MegaLM).
- Endorsement: **by TensorPlay**.
- Tagline: **Learning in motion.**
- Category: reinforcement learning infrastructure (provisional).
- Mark: **Policy Loop M**. Citron represents policy/action trajectory; cyan represents feedback/return; orange represents the reward signal. This is a metaphor, not a system diagram.

## System
| Color | HEX | Role |
|---|---|---|
| Midnight Navy | #07131B | background |
| Electric Citron | #B4EC62 | primary policy path |
| Vivid Cyan | #18BFD1 | feedback path |
| Warm Orange | #FF995B | reward accent |
| Snow White | #F5F8FA | main text |
| Muted Steel | #AABFC7 | secondary text |

MegaLM and MegaRL share typography, palette, and endorsement, but the former uses a directional token stream and the latter a feedback loop. On white use the dedicated darker-color variant or monochrome. Avoid gradient fills on the mark. Use Inter Display for headings and Inter for body text. Wordmark lettering is converted to vector paths to avoid font dependencies. Fonts are not bundled.

## Usage
Use the dark lockup on #07131B, light lockup on white, and monochrome for print. Keep clear space of approximately 20% of symbol width; use the icon for small applications (32 px recommended; favicon simplified by presentation). Do not stretch the mark, recolor its parts arbitrarily, or claim official endorsement before approval.

## Deliverables
`assets/` contains SVG and PNG symbols, horizontal lockups, wordmarks, app icon, favicon, GitHub banner, Open Graph image and wallpaper. `design-tokens.css` defines palette tokens. `concept-brand-board.png` is an AI-generated concept illustration; the SVGs are the editable source of truth and may differ slightly in geometry or light-mode colors.

## Before release
Confirm the product category, actual functionality, brand capitalization and naming/trademark clearance with the team. Approve the logo and test it in GitHub, documentation and the MEGA UI.

The asset preview shows the actual exported files. Stacked logos and a color-system reference are included in SVG and PNG.
