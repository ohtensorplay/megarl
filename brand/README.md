# MegaRL Brand Kit — concept v0.1

Start with `asset-preview.png` for the actual deliverables and `BRAND-GUIDELINES.md` for usage. `concept-brand-board.png` is the earlier visual concept, not the master logo.

- `assets/logo-*`: transparent vector and raster marks and lockups.
- `assets/wordmark-*`: text-only marks.
- `assets/app-icon-*`, `assets/favicon*`: application and browser icons.
- `assets/github-banner-*`, `assets/social-og-*`, `assets/wallpaper-*`: communication templates.
- `assets/color-system.*`, `design-tokens.css`: palette and web tokens.

SVG wordmark paths are outlined; no fonts are distributed. This is a proposal, not an approved identity.
